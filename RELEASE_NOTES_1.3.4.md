# Immich Backup Manager 1.3.4

## Deutsch

Version 1.3.4 verbessert den Programmkopf und bindet das neu bereitgestellte längliche Logo direkt in die Anwendung ein.

### Änderungen

- Neues `Logo-Programm(3).png` als Programmkopf-Logo übernommen
- Sehr schwach sichtbare Randpixel am oberen Logorand entfernt
- Logo größer und proportional mit hoher Auflösung dargestellt
- Beschreibungstext 36 Pixel rechts neben dem Logo positioniert
- Beschreibungstext zweizeilig angeordnet
- Schriftgröße und Kontrast des Beschreibungstextes erhöht
- Textbereich begrenzt, damit er nicht über die gesamte Fensterbreite auseinandergezogen wird
- Schaltflächen für Darstellung, Sprache und Info mittig zum Textblock ausgerichtet
- Oberen Leerraum im Programmkopf reduziert
- Programmversion auf 1.3.4 erhöht

## English

Version 1.3.4 improves the application header and integrates the newly supplied horizontal logo directly into the program.

### Changes

- Added the new `Logo-Programm(3).png` as the application header logo
- Removed very faint edge pixels along the upper logo border
- Displayed the logo larger, proportionally, and at high resolution
- Positioned the description 36 pixels to the right of the logo
- Split the description into two lines
- Increased the description font size and contrast
- Limited the text area to prevent excessive horizontal stretching
- Vertically centered the theme, language, and information buttons with the text block
- Reduced unused space at the top of the header
- Updated the application version to 1.3.4
