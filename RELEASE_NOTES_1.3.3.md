# Immich Backup Manager 1.3.3

## English

Version 1.3.3 updates the visual branding of the Immich Backup Manager. The user-provided horizontal PNG logo is now displayed directly in the application header. The descriptive text is placed to its right and automatically switches between German and English.

The user-provided square program icon now replaces the previous icon inside the application, in the Windows title bar, and as the executable icon. The Windows ICO contains separately generated sizes from 16 to 256 pixels for clear display at different scaling levels.

### Changes

- Added the new horizontal logo to the program header
- Added the adjusted description text beside the logo
- Replaced the in-program and title-bar icon
- Rebuilt the Windows executable icon in multiple sizes
- Updated the application version to 1.3.3

---

## Deutsch

Version 1.3.3 erneuert die optische Darstellung des Immich Backup Managers. Das vom Benutzer gelieferte längliche PNG-Logo wird jetzt direkt im Programmkopf angezeigt. Rechts daneben steht der angepasste Beschreibungstext, der automatisch zwischen Deutsch und Englisch wechselt.

Das ebenfalls gelieferte quadratische Programmicon ersetzt jetzt das bisherige Symbol im Programm, in der Windows-Titelleiste und als Symbol der ausführbaren Datei. Die Windows-ICO-Datei enthält getrennte Größen von 16 bis 256 Pixeln, damit das Symbol bei unterschiedlichen Darstellungen möglichst klar bleibt.

### Änderungen

- Neues längliches Logo in den Programmkopf eingebaut
- Angepassten Beschreibungstext rechts neben dem Logo ergänzt
- Programmsymbol im Programm und in der Titelleiste ersetzt
- Windows-EXE-Symbol in mehreren Größen neu erstellt
- Programmversion auf 1.3.3 erhöht
