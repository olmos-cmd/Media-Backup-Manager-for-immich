DESCRIBE THIS RELEASE
## English

Version 1.3.4 improves the visual layout of the Immich Backup Manager header.

The supplied horizontal program logo is now integrated more cleanly into the application. The description text starts closer to the logo, is split across two lines, and uses a larger and brighter font for improved readability. The theme, language, and information buttons are vertically aligned with the text block, and unused space in the upper header area has been reduced.

The faint bright edge previously visible at the top of the displayed logo has also been removed.

### Changes

- Integrated the supplied horizontal logo into the program header
- Positioned the description text 36 pixels to the right of the logo
- Added a compact two-line description layout
- Increased text size and brightness
- Vertically centered the header buttons beside the text block
- Reduced upper spacing in the header
- Removed the faint bright edge at the top of the logo
- Updated the application version to 1.3.4
- Updated README, changelog, and release notes
