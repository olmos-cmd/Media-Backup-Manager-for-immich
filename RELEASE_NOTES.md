# Media Backup Manager 1.4.5

## Deutsch

Version 1.4.5 ersetzt das zuvor versehentlich verwendete falsche Programmlogo durch das neu gelieferte Original-Logo.

- Neues `header_logo.png` unverändert eingebunden
- Keine Bildbearbeitung und keine Neuzeichnung
- Anzeige proportional an das tatsächliche Seitenverhältnis 1245:615 angepasst
- Lanczos3-Vorskalierung erfolgt nur im Arbeitsspeicher
- Programmversion auf 1.4.5 erhöht

## English

Version 1.4.5 replaces the previously used incorrect application logo with the newly supplied original logo.

- New `header_logo.png` embedded unchanged
- No image editing or redrawing
- Display adjusted proportionally to the actual 1245:615 aspect ratio
- Lanczos3 prefiltering is performed in memory only
- Increased the application version to 1.4.5
