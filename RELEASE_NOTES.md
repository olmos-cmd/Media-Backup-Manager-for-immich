# Media Backup Manager 1.6.2

## Deutsch

Version 1.6.2 behebt gezielt das Überzeichnen und die sichtbaren Überlappungen beim Scrollen in der Albumansicht.

- gesamter Karteninhalt wird auf den sichtbaren Scroll-Viewport begrenzt
- Titel können nicht mehr über die Such-/Button-Zeile malen
- Thumbnails, Kartenhintergrund, Dateianzahl und Badge werden korrekt geclippt
- feste Kartenhöhe und fester Zeilenabstand bleiben unverändert
- Raster und Spaltenlogik bleiben unverändert
- Programmversion auf 1.6.2 erhöht

## English

Version 1.6.2 specifically fixes overdraw and visible overlap while scrolling the album view.

- all card content is clipped to the visible scroll viewport
- titles can no longer paint over the search/button row
- thumbnails, card background, file count, and badge are clipped correctly
- fixed card height and row spacing remain unchanged
- grid and column logic remain unchanged
- increased the application version to 1.6.2
